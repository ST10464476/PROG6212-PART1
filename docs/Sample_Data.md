# 🧪 RaceDay Sample Data

## Overview

Sample data was added to the RaceDay database to test the relationships between the main entities and confirm that the database can store realistic event information.

## Users

The database contains:

- 2 Organisers
- 2 Participants

## Events

Three sample events were added:

- Johannesburg City Run
- Pretoria Charity Walk
- Cape Town Cycle Challenge

## Categories

Each event contains categories based on participation type, distance and age group.

## Enrolments

Sample participant enrolments were added to demonstrate how participants are linked to events.

Different payment statuses are also included for testing.

## Purpose

The sample data provides realistic records that can be used when testing the RaceDay database and, later, the REST API.

The data can be viewed using SQL queries in SQL Server Management Studio.
