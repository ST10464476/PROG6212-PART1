# ⚙️ RaceDay System Features

## Overview

RaceDay is designed around the main activities involved in organising and participating in road running, walking and cycling events.

## 🔐 User Authentication

Users will be able to register and log into the system.

The system will identify whether the user is an **Organiser** or **Participant** and provide access based on their role.

## 🏃 Event Management

Organisers will be able to create and manage event information such as:

- Event name
- Event date
- Location
- Distance
- Entry fee
- Event status

## 🏷️ Event Categories

Each event can have different categories based on factors such as distance and age group.

## 📝 Participant Enrolments

Participants will be able to enrol for available events.

The system will store enrolment information and payment status.

## 🏆 Race Results

Organisers will be able to record participant results, including finishing time, position and average pace.

Participants will be able to view their results.

## 🗺️ Routes & Weather

The system will store useful event information such as route details and weather conditions.

## 🔄 Future Development

These features will be expanded during the API development in Part 2 and the MVC web application development in Part 3.
