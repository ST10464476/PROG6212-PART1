# 🌐 RaceDay API HTTP Methods

## Overview

The RaceDay API will use standard HTTP methods to perform different operations on system resources.

## GET

Used to retrieve information.

Examples:

- View available events
- View event details
- View categories
- View enrolments
- View results

## POST

Used to create new information.

Examples:

- Register a user
- Log in
- Create an event
- Create a category
- Create an enrolment
- Record a result

## PUT

Used to update existing information.

Examples:

- Update a user profile
- Update an event

## DELETE

Used to remove information when authorised.

Example:

- Delete an event

## API Design

Using standard HTTP methods helps keep the RaceDay API structured, predictable and easier to integrate with the future MVC application.
