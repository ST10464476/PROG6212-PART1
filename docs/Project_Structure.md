# 📁 RaceDay Project Structure

## Overview

The RaceDay repository is organised to keep project documentation, configuration and future development work clearly separated.

## Main Folders

### `docs/`

Contains the planning and database documentation for Part 1.

This includes:

- RaceDay ERD
- API Endpoint Plan
- SQL Server Database Script
- ERD Description
- Database Description
- API Overview
- Project Requirements
- System Features
- Database Validation

### `.github/workflows/`

Contains the GitHub Actions workflow used to automatically validate the required project structure and documentation.

### `README.md`

Provides an overview of the RaceDay system, project objectives, technologies and development progress.

## Future Structure

As development continues, the repository will be expanded to include the REST API and MVC web application.

The structure will continue to be organised so that project components are easy to locate and maintain.
